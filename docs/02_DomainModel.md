# ドメイン設計

このシステムでは「Person（人物）」を中心として設計しています。

```
User

↓

Person

↓

PersonMedicalHistory

↓

MedicalCondition
```

## User

ログインするユーザー。

必ずしも家系図上の人物とは一致しません。

例

- 自分
- 家族

※祖父母や故人はログインアカウントを持たないことも想定 (ただし、Personのみ登録)

---

## Person

家系図上の人物です。

人物は

- 実父
- 実母

を自己参照で保持します。

兄弟姉妹は専用テーブルを持たず、父母が一致する人物を検索して取得します。

---

## MedicalCondition

病名マスタです。

同じ病名を複数人物が利用できるよう、独立したマスタとして管理します。

---

## PersonMedicalHistory

人物と病名を結びつける中間テーブルです。

ここに

- 発症年齢
- 診断日
- 状態
- メモ

などを保持します。

これにより、一人が複数の病歴を持つことができます。
